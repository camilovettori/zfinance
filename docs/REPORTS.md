# Reports

HomeCoin includes a reporting view that combines charts, printable summaries, and export actions.

## What the Reports View Covers

- balances over time
- income versus expense
- top categories
- budget usage
- weekly summary
- forward forecast

## Export Formats

- PDF report export via jsPDF
- CSV export for transactions
- print-friendly A4 layout

## Print Layout

The report styles include print-specific CSS so the summary can be exported cleanly on paper or as PDF.

## Typical Uses

- monthly household review
- budget check-ins
- expense category analysis
- end-of-period planning

## Notes

The report data is calculated from the current in-memory state, so it always reflects the latest saved local data.
